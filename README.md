\# ReconX — OSINT Reconnaissance Tool



A Python 3 desktop application for OSINT reconnaissance built with Tkinter GUI.



\## Features

\- WHOIS Lookup

\- DNS Enumeration

\- Subdomain Scanner

\- Port Scanner

\- HTTP Headers Analysis

\- Geolocation via IP-API

\- SQLite persistence

\- CSV \& TXT export



\## Installation

pip install python-whois requests dnspython



\## Run

python reconx.py



\## Test

python test\_reconx.py
